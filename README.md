# Rubra · Brasa e Vinho

Site de um restaurante fictício de brasa e vinho em São Paulo, feito como peça de portfólio.

**Projeto fictício.** Endereço, telefone, WhatsApp e e-mail são inventados. A reserva e o newsletter mostram validação e confirmação na tela, mas não enviam nada.

## O que tem na página

- Vídeo de carne na grelha no topo, com fotos que se espalham conforme a página rola
- Cardápio em carrossel com cinco abas: brasa, entradas, sobremesas, drinks e vinhos
- Experiências (almoço de domingo, happy hour e eventos) com botão que já preenche a reserva
- História da cozinha, perguntas frequentes e formulário de reserva com regras de dia e horário
- Layout para celular, navegação por teclado e respeito a quem prefere menos movimento

## Tecnologia

HTML, CSS e JavaScript puro, sem framework e sem etapa de build para publicar. Basta servir a pasta como site estático.

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/      fotos em webp
assets/video/    vídeo do topo
```

A pasta `src/` guarda os modelos usados para gerar esses arquivos a partir do protótipo.
